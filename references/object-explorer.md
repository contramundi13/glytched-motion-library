## Original reusable direction — proposed

An **Object Explorer** moves from an original brand statement to annotated product details. Possible adaptations: an Inspired Creations shirt/hoodie customization study, using approved garment artwork and actually supported options, or a Glytched sculptural digital object with restrained cyan/magenta light. Neither adaptation is implemented here.

Use an original/licensed product image sequence or model. Begin with a still and semantic detail list; add limited view changes only if the assets and budget justify them. A 2D image sequence or CSS composition can be sufficient. Treat WebGL as optional, not a source-proven requirement. If scroll progression is selected, preserve native scrolling and a short natural range. Provide explicit touch/keyboard controls rather than relying on hover, dragging or scrolling alone.

Keep headings, labels, specifications, navigation and CTA in HTML. Leader lines are decorative; associate each annotation with a readable detail entry. On phones, show details below the image instead of crowding labels around it. Use meaningful alt text, visible focus, adequate contrast and comfortably sized controls, improving on tiny recorded indicators rather than copying them.

Expose brand/copy, approved object assets, views/focal points, material/color options, annotation text/anchors, palette/type, interaction mode, motion limits, fallback image and actual CTA destination. Color previews must not imply unavailable products or verified material accuracy. Do not invent fit/fabric claims, endorsements or commercial partnerships.

Reduced motion, no-JS and renderer/media failure must retain a static object, all essential detail text and a working CTA. Compress responsive assets, declare dimensions, defer secondary views, pause offscreen work and dispose renderers/listeners on teardown. Test pointer, keyboard and touch paths, labels at narrow widths, contrast, fallback states and measured loading/frame stability before claiming readiness. **No implementation QA exists for this recipe.**
